# Video Creator 自动化视频渲染工具

基于 Python + Pillow + FFmpeg 的自动化口播/播客演示视频渲染工具，专为知识口播、长文自述、名人格言类长视频打造。

---

## 目录结构

```
video-creator/
├── tools/
│   ├── template_builder.py    # 背景与右下角大人物贴图合成模块
│   ├── logo_builder.py        # 左上角圆形金属质感旋转头像 Logo 裁剪生成模块
│   ├── subtitle_generator.py  # 智能自然分句、字数加权时间轴分配与字幕导出（SRT / ASS）
│   ├── slide_renderer.py      # 紧凑双行自适应字幕卡片高清无损渲染（浅灰微透底、黑边白字）
│   └── video_renderer.py      # FFmpeg 流式硬件加速压制引擎（动态旋转 Logo、BT.709 色彩校准）
├── make_video.py              # 统一命令行入口
├── bg.jpg                     # 原始背景图 (1792x1008)
├── munger-nobg.png            # 人物无背景图 (750x750)
├── template.png               # 一次性预合成的高清模板底图
├── logo_avatar.png            # 预生成的左上角圆形旋转徽章
├── 翻身不需要运气.txt         # 原始台词文稿
├── 翻身不需要运气_*.mp3       # 完整长音频 (28分21秒)
└── output_sample_30s.mp4      # 30 秒测试样本视频
```

## 核心设计特性

1. **左上角顺时针旋转圆形 Logo**：
   - 自动基于人物头部截取特写，配以双层银白金属外环与深色底衬；
   - 带有自适应外边距保护（Safe Canvas），360 度顺时针旋转过程中绝对不会切边、变形；
   - FFmpeg 硬件加速动态叠加，旋转转速平稳沉稳（默认 10 秒/圈）。
2. **紧凑双行自适应字幕卡片（70% 宽度）**：
   - 单行字符数严格限制在 11 字以内，卡片宽度自动缩短至原本的 70%；
   - 长字幕智能对称折为两行，左侧留出 300+ 像素宽裕呼吸空间，右侧距人物保持安全距离；
   - 浅灰半透明底卡 + 黑色外边框 + 纯白大字黑边描边。
3. **100% 原色零遮罩直出**：
   - 除字幕卡片外不加任何全局蒙层；
   - 模板底图按 0-255 全范围直通编码，不再压缩到 16-235，画面色调与 `template.png` 完全一致；
   - 注入标准 BT.709 与 H.264 VUI 元数据，并同步标记全范围，避免播放器按有限范围二次拉伸导致的 Gamma 变暗/变色；
   - 如需传统有限范围（16-235）投放，可加 `--tv_range` 回退。
4. **极速导出**：
   - 配合 Apple Silicon `h264_videotoolbox` 硬件加速，实测 30 秒 sample 仅耗时 **4.6 秒（6.5x 实时速度）**；渲染 28 分 21 秒全长视频仅耗时 **234 秒（3 分 54 秒，7.26x 实时速度）**。

## 常用命令

### 1. 快速生成 30 秒测试样片（默认）
```bash
python3 make_video.py --duration 30
```

### 2. 生成完整视频（28分21秒全长）
```bash
python3 make_video.py --output output_full.mp4
```

### 3. 参数配置
- `--duration <秒数>`: 指定生成的视频时长（不填则为整段音频全长）。
- `--no_logo`: 关闭左上角旋转 Logo。
- `--logo_period <秒数>`: 调整 Logo 旋转一圈所需的时间（默认 10.0 秒，即每秒匀速旋转 36 度）。
- `--tv_range`: 改用传统有限范围（16-235）编码；默认全范围直通，保证视频色调与模板图完全一致。
- `--rebuild_template`: 强制重新生成模板图和旋转 Logo。
