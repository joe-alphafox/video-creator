## 三、原创声明方式

### 3.1 B 站机制（回答"怎么声明原创"）

B 站视频**没有**独立的"原创声明"勾选框，声明原创的路径是：

1. **投稿时稿件类型选"自制"**（相对选项是"转载"，转载必须填写来源链接）。选"自制"即等同于声明原创。
2. **可选开启"禁止转载"**：开启后视频页会显示"未经作者授权，禁止转载"标识，并进入版权保护范围。
3. **另有"创作声明"（含 AI 合成声明）**：2025 年起，使用 AI 生成/合成的音视频必须主动勾选"该视频使用人工智能合成技术"，否则平台会强制加标。这类声明与"自制/转载"是两个独立维度。

补充说明：**只有专栏（图文）稿件**有单独勾选的"原创声明"功能；视频端靠上面的稿件类型完成声明。

**违规红线**：转载内容必须选"转载"。简单搬运、无实质加工的片段截取、未授权翻译字幕、录屏、单纯倍速/镜像/调色等均不属于自制；转载冒充自制会导致稿件下线、信用分扣除、激励收回乃至封号。

### 3.2 该账号的实际情况

抽样 108 条视频（按历史均匀抽样 80 条 + 播放量 Top 30，去重后 108 条），逐条读取稿件类型、禁止转载标识、简介与动态字段：

| 项目 | 结果 |
|---|---|
| 稿件类型 | **108/108 全部为"自制"体系，0 条标注为"转载"** |
| 开启"禁止转载" | 32 条（30%） |
| 简介（`desc`） | **100% 为空**，未填写任何文字 |
| 动态（`dynamic`） | 100% 为空 |
| AI 合成声明 | 抽 12 条查 `arc_aigc` 字段，**全部为 `null`**，未做 AI 声明 |
| 标题含"原创" | 0 条 |

**时间线上的明显切换**：

- 2025-11-26 及之前：稿件为"自制 + 开启禁止转载"组合。
- **2025-12-04 起**：新投稿全部切换为另一种自制记法，且**不再开启"禁止转载"**。

即该账号的"声明原创"动作仅两步：**投稿类型选自制 + 简介留空**（不写来源、不标转载、不做 AI 声明）。

### 3.3 关于接口 `copyright` 字段的取值说明

`x/web-interface/view` 返回的 `copyright` 字段，官方 API 文档只列出 `1`（原创/自制）与 `2`（转载），实际抓取中还会出现 `3`。本次核对的判断依据：

- 抽到的 `copyright = 3` 样本中，7% 带来源标注，且**部分同时开启了"禁止转载"**（该选项只对自制稿件开放）；
- 老番茄、影视飓风、哔哩哔哩纪录片等公认自制账号也在使用取值 `3`；
- 对照：典型转载内容（`copyright = 2`）有 54% 带来源标注。

因此 `3` 属于"自制"体系、**不等于转载**，本报告将其计入原创。`1` 与 `3` 的确切官方差异未能确认（一种可能是对应是否允许转载，二者高度相关但非严格一一对应）。

## 四、对本项目的可复用要点

1. **标签占满 10 个**，不留空位。
2. **前 6 位用大盘流量词**（心理学、心理、人性、人际关系、社交、社会、情感、个人成长、强大、人生、男人/男人成长），**后 4 位放当期主题词**（名人、学派、系列名）。
3. **建立自造系列名**并长期复用（该账号自造系列名的复用次数超过任何单个名人），比单纯借势名人更能沉淀品牌。
4. **固定模板 + 局部替换**，39 组标签组合被复用 105 次，不必每条重新构思。
5. **分区高度集中**（89% 投在同一分区），利于算法建立账号垂直度。本项目对应长口播类内容可优先 `社科·法律·心理`。
6. **原创声明**：投稿类型选"自制"，需要版权保护时开启"禁止转载"；如使用 AI 合成人声/画面，**必须主动勾选 AI 合成声明**（该账号未做此声明，属于合规风险点，不建议照搬）。
7. **注意标题与人名的对应关系**：该账号大量使用名人署名做标题，若引用未经授权的内容需评估版权与平台风险。
